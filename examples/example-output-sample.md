# DemoBrand 爆款复刻示例输出

> `DemoBrand` 是本仓库为演示流程编造的**虚构示例品牌**，不对应任何真实公司或产品。
> 示例用途：展示这个 Skill 跑完后应该交付什么。真实执行时请以生成的 `ecommerce-viral-remix-package.md` 为准。

## 输入

- 爆款来源：TikTok/Reels/Shorts 割草机产品视频或竞品文章
- 自家产品：DemoBrand 机器人割草机
- 目标平台：TikTok/Reels/Shorts/独立站
- 目标时长：30 秒

## 输出摘要

### 1. 原爆款内容拆解摘要

爆点来自“周末不用再手推割草”的强痛点，以及机器人从充电座出发、自动割草、割前割后对比、自动回充的完整证明链。前 3 秒必须直接展示痛点和反差：人工推割草机很累 vs 机器人自动工作。

### 2. 可复用爆款公式

痛点提问 → 自动化解决方案亮相 → 功能证明 → 前后对比 → 回充闭环 → 品牌口号。

### 3. 自家产品卖点映射表

| 爆款元素 | 原内容表达 | DemoBrand 替换 | 画面证明 |
|---|---|---|---|
| 周末劳动痛点 | 人工割草麻烦 | “还在自己割草？” | 人推割草机疲惫镜头 |
| 自动化方案 | 机器开始工作 | DemoBrand 从充电座出发 | 白色机身、DEMO BRAND Logo、红色 STOP 键 |
| 控制方式 | 简单启动 | App/扫码连接 | 手机界面 + 机身二维码 |
| 结果证明 | 草坪变整齐 | 割前/割后对比 | 同角度 before/after |
| 闭环安心 | 自动回去 | 自动回充 | 机器驶回充电座 |

### 4. 原创宣传脚本

0-3s：字幕“还在把周末浪费在割草上？”画面：人推割草机满头汗，镜头快速切到 DemoBrand 静置在充电座。

3-8s：字幕“交给 DemoBrand。”画面：App/扫码连接，DemoBrand 自动离座，白色机身和红色 STOP 键特写。

8-18s：字幕“它自己规划、自己割。”画面：大轮胎穿过草坪，黑色 PUSH 高度调节旋钮特写，机器稳定前进。

18-25s：字幕“看得见的整齐。”画面：草坪割前/割后分屏对比。

25-30s：字幕“DEMO BRAND - Let weekends be weekends.”画面：DemoBrand 自动回充，主人坐下喝咖啡。

### 6. 视频生成提示词

生成一支 30 秒 TikTok 风格机器人割草机广告。主体是白色 DemoBrand 机器人割草机，带 DEMO BRAND Logo、红色 STOP 键、黑色 PUSH 高度调节旋钮和大轮胎。场景是阳光下的郊区别墅草坪。开头展示人工割草疲惫，随后手机 App/扫码连接，机器人从充电座自动驶出，稳定割草，展示割前割后对比，最后自动回到充电座。镜头节奏快，前三秒强钩子，产品特写清晰，真实生活方式广告风格。禁止出现竞品 Logo、原视频人物、夸张虚假效果、危险操作。

### 7. 素材补拍清单

- 产品素材：白色机身、DEMO BRAND Logo、红色 STOP 键、黑色 PUSH 旋钮、大轮胎、充电座。
- 场景素材：未割草坪、割后草坪、主人休息场景、手机 App/扫码连接。
- 证明素材：自动离座、自动割草、割前/割后同角度对比、自动回充。
