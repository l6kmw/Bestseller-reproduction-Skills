# 电商爆款内容分析框架

## 1. 前3秒钩子

前3秒必须同时拆两条线：

- 文案钩子：痛点、反常识、悬念、利益、数据、场景。
- 视觉钩子：画面突变、产品堆叠、动作冲击、第一人称POV、视觉奇观、文字弹出。

必须回答：

- 第0秒第一帧是什么？
- 观众为什么会停下来？
- 文案和画面是否强化同一个信息？
- 声音/BGM/音效是否参与钩子？
- 钩子强度评分 1-10。

## 2. 分镜结构

| 时间 | 景别 | 画面内容 | 字幕/旁白 | 转场 | 目的 |
|---|---|---|---|---|---|

重点看产品在第几秒出现、结果证明是否清楚、CTA 是否自然。

## 3. 转化逻辑

常见路径：

- 痛点 → 产品 → 使用过程 → 结果 → CTA。
- 反常识 → 解释 → 产品方案 → 证明 → CTA。
- 场景共鸣 → 麻烦放大 → 自动化方案 → 省心结果 → 品牌记忆。

## 4. 可复制/不可复制

可复制：钩子句式、镜头顺序、节奏模型、场景结构、证明链、CTA方式。

不可复制：原品牌、Logo、产品外观、原人物、达人、声音、原字幕、原音乐、原画面、未授权数据或背书。

## 5. 产品证明链

用户痛点 → 产品出现 → 用户操作 → 核心功能运行 → 可见结果 → 省心/省钱/省时间 → CTA。

## 6. 合规红线

避免绝对化用语、无证明功效、贬低竞品、复制原素材、夸大 AI/自动化能力。
