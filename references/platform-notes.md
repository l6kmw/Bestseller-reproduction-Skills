# 平台适配笔记

## TikTok / Reels / Shorts

- 前1秒必须有视觉动作。
- 字幕要短，大字，强对比。
- 适合英文痛点句 + 快节奏画面。
- CTA 不要太硬，可以用品牌记忆或软引导。

## 抖音 / 千川

- 前3秒更强调痛点和利益。
- 卖点表达要直给。
- 避免绝对化和无证明功效。
- CTA 可以更明确。

## 小红书

- 更像真实体验，不要太广告。
- 多用场景和生活方式表达。
- 适合“我终于不用……”这种口吻。

## 独立站 / Amazon

- 更强调产品可信度和功能证明。
- 镜头要清楚，少花字，多产品细节。
- 适合 30-60 秒说明型广告。
